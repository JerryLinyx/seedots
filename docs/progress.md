# SeeDots 开发进度

最后更新：2026-10-22。记录技术侧的任务、里程碑和每周进展，回答“现在做到哪了、下一步谁做什么、卡在哪”。

**和其他文档的分工**

- 需求做到什么程度，看 [`tech-plan.md`](tech-plan.md) §11 需求追溯（PRD §5 的状态列与它同步）。本文不再重复每条需求的状态，只记**任务**。
- 书面材料、预算、导师联系等非技术待办仍在团队空间的“团队分工与 Todo”页。

**维护方式**

- 每个任务一行，编号 `T` + 两位数字，不复用。状态只用：`待开始`、`进行中`、`完成`、`阻塞`、`取消`。
- 开始做就改成`进行中`并写上负责人；完成时在“结果”列写提交号或 PR，并把对应需求的状态同步到 tech-plan §11 和 PRD §5。
- 每周一在“周报”最上面加一段：上周完成、本周计划、风险与需要决策的事。
- 团队成员和 Claude 都会编辑本文件，在原文上增改，不整篇重写。
